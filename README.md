## **RESILIENCIA ANDINA**
Este proyecto es una plataforma web interactiva y responsiva diseñada para simular y analizar los efectos de la crisis económica actual en diferentes sectores estratégicos de Bolivia. A través de **6 simuladores matemáticos independientes**, el sistema permite proyectar variables críticas como el desabastecimiento de carburantes, la inflación en la canasta básica, la brecha cambiaria en las importaciones y la sostenibilidad del presupuesto familiar alteño y paceño.

El sitio integra una sección ejecutiva de **Fichas Técnicas Estáticas (Casos de Estudio Guía)** que sirven como manual de usuario para validar el correcto funcionamiento de los algoritmos de simulación.

---

## 🚀 Características Principales
* **Sección de Casos de Estudio Fijos:** Tablas organizadas de tres en tres que muestran datos técnicos preconfigurados y especifican el "Resultado esperado" de cada simulación.
* **6 Simuladores Interactivos:** Módulos que capturan entradas y procesan ecuaciones matemáticas en tiempo real.
* **Diseño Tricolor Temático:** Interfaz estilizada con los colores de la bandera boliviana combinados con un modo oscuro premium.
* **Efectos Visuales Avanzados:** Ventanas flotantes, animadas con CSS puro para visualizar evidencias fotográficas sin recortes.
* **Estructura Ultra-Responsiva:** Adaptabilidad garantizada para computadoras, tablets y celulares a través de CSS Grid y Flexbox.

## 📐 Casos de Estudio y Parámetros de Validación

La plataforma contiene 6 configuraciones oficiales de prueba estructuradas para contrastar los resultados del sistema:

| # | Simulador | Inputs Requeridos | Resultado Esperado |
| --- | --- | --- | --- |
| **1** | **Reserva de Carburante** | Reserva inicial, Consumo, Reabastecimiento, Nivel crítico | Días estimados para alcanzar el desabastecimiento crítico. |
| **2** | **Comercio Informal** | Precio inicial, Tasa de especulación, Subsidio, Límite máximo | Proyección de días en los que el producto duplica su costo. |
| **3** | **Sector Importador** | Monto de importación, Cambio oficial/paralelo, Arancel | Brecha financiera y sobrecosto real en adquisición de divisas. |
| **4** | **Presupuesto Familiar** | Ingreso mensual, Gasto fijo, Inflación, Fondo de emergencia | Balance neto y sostenibilidad del fondo de reserva. |
| **5** | **Bloqueos de Rutas** | Tiempo base, Puntos de bloqueo, Demoras, Costo operativo | Tiempo total de arribo e incremento porcentual logístico. |
| **6** | **Control de Precios** | Precio máximo, Costo producción, Margen ganancia, Escasez | Viabilidad financiera y riesgo de aparición de mercados negros. |

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de formularios, tablas informativas y capas modales.
* **CSS:** Variables globales, CSS Grid Layout, Flexbox, animaciones cúbicas de transición y filtrado de desenfoque.
* **JavaScript :** Manipulación del DOM, validación lógica de datos de entrada y ejecución de fórmulas matemáticas financieras.

## ⚙️ Instrucciones de Uso e Instalación

1. **Clonar o Descargar el Proyecto:**
Asegúrate de mantener la estructura de carpetas intacta (`css/`, `js/`, `img/`).
2. **Configurar Imágenes Propias:**
Guarda tus capturas de pantalla en la carpeta `img/` y verifica que el nombre coincida exactamente en las etiquetas `<img>` de tu archivo `index.html`.
3. **Ejecutar la Plataforma:**
Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox). No requiere servidores locales ni dependencias externas.
